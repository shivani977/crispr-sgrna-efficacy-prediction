# crispr-sgrna-efficacy-prediction
CRISPR sgRNA Efficacy Prediction
A deep learning model for predicting CRISPR single-guide RNA (sgRNA) efficacy using DNA sequence information and genomic metadata, with a focus on cross-cell-line generalization.

Overview
This project uses a neural network to classify sgRNAs into high- and low-efficacy groups based on their normalized efficacy values. The model combines sequence-based features with genomic information and evaluates how well it generalizes across different cell lines using a leave-one-cell-line-out cross-validation strategy.

The key finding: model performance varies significantly by cell line, suggesting that general-purpose CRISPR efficacy models may not be universally reliable, especially in experimentally unique cell types.

Results
The model was evaluated using a leave-one-cell-line-out strategy. For each fold, the model was trained on three cell lines and tested on the fourth held-out cell line.

Key Findings
* The model demonstrated moderate generalization to HeLa, HL60, and HCT116, with AUC scores ranging from 0.64 to 0.74.
* The highest performance was observed on HCT116 (AUC = 0.74), suggesting it shares transferable genomic features with the training cell lines.
* HEK293T showed a stark drop in performance (AUC = 0.37), indicating poor cross-cell-line generalization. This implies HEK293T likely has unique genomic or epigenetic characteristics not captured by the model trained on other cell types.
* A higher AUC indicates better model performance in distinguishing high- vs. low-efficacy sgRNAs. A value of 0.5 means random guessing, while 1.0 means perfect separation.
* ROC curves and AUC bar charts generated by the model are saved to the results folder when the script is run.

Model Architecture

The model combines several neural network components:
- One-hot encoding of sgRNA sequences (20 nucleotides)
- 1D Convolutional Neural Networks (CNNs) for sequence feature extraction
- Bidirectional LSTM layers for learning sequential patterns
- Multi-head self-attention for enhanced feature representation
- Genomic metadata including chromosome (one-hot encoded) and normalized start/end genomic positions
- Fully connected layers for final binary classification

Pipeline
- sgRNA sequence -> One-hot encoding -> Conv1D + BatchNorm + MaxPool -> BiLSTM -> BiLSTM -> Multi-Head Attention + Residual -> LayerNorm -> Global Average Pooling -> Concatenate with genomic metadata -> Dense(128) -> Dropout -> Dense(64) -> Dropout -> Dense(1, sigmoid)

The resulting sequence representation is combined with genomic metadata before being passed through fully connected layers to produce a binary classification.

Dataset
The model was evaluated using four cell lines from the DeepCRISPR study (Chuai et al., 2018):
- HeLa
- HCT116
- HL60
- HEK293T

Binary Classification
- High efficacy: normalized efficacy > 0.35, label 1
- Low efficacy: normalized efficacy < 0.15, label 0

Intermediate efficacy values were excluded from the classification task.

Data Availability
The dataset is not included in this repository

To reproduce these results, you will need to obtain the dataset from the original source and place it in the project root with the filename:

13059_2018_1459_MOESM5_ESM (1).xlsx

The Excel file should contain sheets named: hela, hct116, hl60, hek293t, each with columns:

- sgRNA - 20-nucleotide sequence
- Normalized efficacy - continuous efficacy score
- Chromosome - chromosome identifier
- Start - genomic start position
- End - genomic end position

Evaluation
To test generalization across cell types, a leave-one-cell-line-out evaluation strategy was used:
- For each experiment, the model was trained on three cell lines and evaluated on the fourth held-out cell line.
- Training data was further split 80/20 into training and validation sets.
- Class imbalance was addressed by calculating class weights, ensuring balanced learning.
- Early stopping (patience=10) and learning rate reduction (patience=5, factor=0.5) were used to prevent overfitting.

Performance was evaluated using:
- ROC-AUC
- Accuracy
- Precision
- Recall
- Classification reports

- Run the training and evaluation: python crispr_model.py
- View results: ROC curves and AUC bar charts will be displayed and can be saved to the results folder.

Purpose and Future Work
This project explores the use of deep learning to identify sequence and genomic patterns associated with CRISPR sgRNA efficacy and to evaluate whether models trained on one set of cell types can generalize to another.

Future Plans
- Integrate epigenetic data (e.g., chromatin accessibility) to improve cross-cell-line generalization.
- Expand to more diverse cell lines to better understand cell-type-specific effects.
- Use attention maps to identify key sequence features driving predictions.
- Apply findings to real-world CRISPR design tools.
